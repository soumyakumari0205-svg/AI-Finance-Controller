Autonomous Controller Engine Capabilities

Every confidence score traces to actual field comparisons via rapidfuzz. No Math.random() anywhere in this system.

Engine

Fuzzy Match Engine

Exact pass (±0.01 amount, ±3 days, ref overlap) scores 95–100%. Fuzzy pass uses rapidfuzz token_set_ratio weighted with amount/date proximity for 70–94% confidence.

Score

Real Health Score

Weighted formula: match_rate×0.45 + exception_score×0.25 + age_score×0.15 + quality_score×0.15. Stored per run for trend history.

Audit

Immutable Audit Log

Every match, exception, and anomaly writes atomically to audit_log. DB-level REVOKE prevents UPDATE/DELETE. RLS policies enforce it.

Auth

Supabase JWT Auth

Every API route verifies the Supabase JWT. Controller role required to approve/reject exceptions. Viewer role for read-only access. No service key in the browser.

Anomaly

Real Anomaly Detection

Duplicate payout (same vendor/amount/gateway/24h), fee variance drift vs trailing 90-day avg, and off-schedule billing detection.

Forecast

Server-Side Forecasting

What-If sliders call POST /api/forecast/what-if and recompute from real DB data server-side. Bar heights reflect actual projected balances.
